SmartReview — Preparer & Reviewer Journey Map

Prototype: SmartReview-ProtoC2  ·  Return: Jessica Drake 1040  ·  Preparer: Sara Chen  ·  Reviewer: Jordan Lee

Overview

SmartReview splits tax return review into data accuracy first, insights second. Sara (preparer) completes Pass 1 in two sequential phases—import accuracy, then AI diagnostics—before handing the return to Jordan (reviewer). Jordan opens a Pass 1 briefing (activity log), then begins Pass 2 with a phased reviewer checklist, output attestation, and sign-off. The Smart review brief is the shared handoff surface across both roles.

Handoffs

  1. Preparer → Reviewer (Send to reviewer)

    Trigger: Sara completes Pass 1 and chooses Pass to reviewer → Send to reviewer.

    Transfers: Handoff snapshot, activity log (docs verified, flags cleared, edits, summary checks, diagnostics), preparer attestations, notes, live amounts.

  2. Pass 1 briefing → Pass 2 (Begin Pass 2 review)

    Trigger: Jordan reads activity log and clicks Begin Pass 2 review.

    Transfers: Session state persists; UI switches to Pass 2 with Reviewer checklist tab and four strategic phases.

  3. Pass 2 complete → Sign-off

    Trigger: Checklist attested, outstanding items = 0, Rev confirmations current.

    Transfers: Reviewer attestation + manual checklist = record of Pass 2 approval.
